
#	東方っぽい奴 by Shooting68K


１．これは何？

	シューティングゲームツクール的なツール、Shooting68KZを使ったデータです。
	ゲーム本体の再配布も認められているので、起動するディスクイメージにしています。


２．使い方

	X68000Zなど、X68000シリーズ互換のハードのFD0に入れるとゲームが起動します。


３．保証・配布規定

	Shooting68KZは無償の範囲で配布が認められているので、その範囲でお願いします。
	（エディタはダメみたいです、ここには入れてないけど…）
	https://stg68k.remotex.co.jp/

	東方Projectのキャラクタを使わせていただいてます。
	「上海アリス幻樂団」様の二次創作ガイドラインに従って作成しています。
	https://touhou-project.news/guideline/

	主人公とボスの二人だけ「点睛集積」様のdot絵を使用させていただいています。
	https://dot-sh.com/

	画像データのコンバートに「カタ」様のツールを利用させていただいています。
	https://github.com/kata68k/X68000_Tools_STG68k_CNV

	サウンドはそれっぽく音をOPMで鳴らしています。
	ここまで似てなければ問題にならないと思いますが…。


	Shooting68Kはメインのゲームプログラムも弄っています。
	Ｖの方は少しだけデータ弄ればお手持ちのデータでも遊べるかもしれません。

	STG68KGV.x	（VBLANK check と 384 * 256 mode と
				　タイトル画面でのESCキー だけ対応）
	STG68KGT.x	（更に弾丸の方向などを勝手に変更）


４．その他

	点稼ぎのポイントアイテム、ボムのシステムが無いので、
	Shooting68Kではそもそも弾幕ゲーは無理でしたー！
	いつか別の方法で再チャレンジしてみたいです（いや時間的に無理か…）
